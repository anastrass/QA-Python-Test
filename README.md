# 🧪 QA Python Tests

Projeto de estudos práticos em **Quality Assurance e automação de testes**, desenvolvido com **Python, Pytest e Selenium WebDriver**.

## 🎯 Objetivo

Praticar conceitos fundamentais de automação de testes, incluindo criação de testes, validações, localização de elementos e interação com aplicações web.

## 🛠️ Tecnologias

- Python
- Pytest
- Selenium WebDriver
- Google Chrome
- Git e GitHub

## 🧪 O que foi praticado

- Criação e execução de testes automatizados
- Uso de `assert` para validações
- Localização de elementos com ID, XPath e Class Name
- Preenchimento de campos e interação com elementos web
- Validação de textos e comportamentos da interface
- Automação de cenários da aplicação Urban Routes
- Exercícios de lógica e funções em Python

## 📁 Principais arquivos

- `validar_botao_scooter.py` — automação e validação da opção Scooter
- `AddressesUrban.py` — preenchimento de endereços na Urban Routes
- `checkText.py` — validação de texto da página
- `click_button.py` — interação com botão da interface
- `test_calc.py` e `calc_multiply_test.py` — exemplos de testes com Pytest
- `perguntas_entrevista.py` — exercícios de lógica em Python

## ▶️ Como executar

Clone o repositório e instale as dependências:

```bash
pip install pytest selenium
```

Execute os testes com:

```bash
pytest
```

> Alguns testes Selenium dependem do ambiente da aplicação utilizado durante o treinamento e do navegador Google Chrome.
